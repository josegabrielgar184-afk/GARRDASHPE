GARRDASHPE

Politica de Privacidad — Actualizada: 16 de julio de 2026

1. Introduccion

GARRDASHPE ("la aplicacion", "el juego") respeta y protege la privacidad de sus usuarios. Esta politica de privacidad explica que datos procesamos, como los utilizamos y que derechos tiene el usuario sobre los mismos. Al utilizar la aplicacion, el usuario acepta las practicas descritas en este documento.

2. Datos que recopilamos

GARRDASHPE recopila los siguientes datos para proporcionar sus funcionalidades de juego, ranking y canje de premios:

  • Correo electronico y contrasena: utilizados unicamente para la autenticacion del usuario mediante Firebase Authentication. La contrasena se almacena cifrada y no es accesible por el equipo de GARRDASHPE.
  • Nombre completo, edad y pais: datos opcionales del perfil de usuario almacenados en Firebase Firestore. Se utilizan para verificar la identidad en el proceso de canje de diamantes.
  • Nickname (Apodo del jugador): nombre publico elegido libremente por el usuario para identificarse en el Ranking Global.
  • Puntuaciones / Records: resultados obtenidos en las partidas (puntos, zombies eliminados, etc.) que se muestran publicamente en la tabla de clasificacion.
  • Monedas virtuales y tiempo jugado: cantidad de monedas obtenidas en el juego y tiempo total jugado, almacenados en Firestore para el calculo de reservas financieras.
  • Solicitudes de canje de diamantes: cuando el usuario solicita canjear diamantes, se almacenan su Player ID, nickname, tiempo jugado y puntos gastados en las colecciones solicitudes_pendientes y solicitudes_confirmadas.
  • Sugerencias: mensajes enviados por los usuarios a traves del formulario de sugerencias, almacenados en la coleccion sugerencias con el correo del usuario.
  • ID de dispositivo: identificador unico generado localmente utilizado unicamente para medidas de seguridad (prevencion de fraude, baneo de dispositivos). Almacenado en Firestore solo cuando un dispositivo es baneado por actividad maliciosa.

GARRDASHPE NO recopila los siguientes datos:

  • Datos financieros, tarjetas de credito ni informacion bancaria.
  • Geolocalizacion ni datos de movimiento del dispositivo.
  • Contactos, mensajes, fotos ni archivos del dispositivo.
  • Identificadores publicitarios (ADID/IDFA) ni datos de navegacion.

3. Como utilizamos los datos

Los datos recopilados se utilizan unica y exclusivamente para:

  • Mostrar el Ranking Global de jugadores en tiempo real dentro de la aplicacion.
  • Identificar al jugador que alcanza la posicion #1 (TOP 1) en el menu principal.
  • Permitir que el usuario vea su progreso comparado con otros jugadores.
  • Procesar y verificar las solicitudes de canje de diamantes.
  • Recibir y atender las sugerencias de los usuarios para mejorar el juego.
  • Calcular las reservas financieras necesarias para el pago de premios.
  • Prevenir el fraude, el hackeo y el uso de herramientas maliciosas (emuladores, VPN, manipulacion de memoria).
  • Identificar y bloquear dispositivos que violan los terminos de servicio.

Estos datos no se utilizan para publicidad, no se venden a terceros, ni se comparten con fines comerciales.

4. Almacenamiento y seguridad

Los datos se almacenan de forma segura en Firebase Firestore, un servicio de Google Cloud que cumple con el RGPD (Reglamento General de Proteccion de Datos) y esta certificado bajo ISO 27001, ISO 27017 e ISO 27018. La informacion se transmite mediante conexiones cifradas (HTTPS/TLS) y se cifra en reposo por defecto.

Las contrasenas se almacenan cifradas mediante Firebase Authentication y no son accesibles por el equipo de GARRDASHPE.

El ID de dispositivo se genera y almacena localmente mediante localStorage. Solo se envia a Firestore cuando un dispositivo es baneado por actividad maliciosa.

El resto de los datos del juego (monedas, mejoras compradas, configuracion de sonido, personaje seleccionado) se almacenan localmente en el dispositivo mediante localStorage del navegador. No se envian a ningun servidor.

5. Datos de menores

GARRDASHPE esta disenado para todas las edades, con clasificacion de contenido PEGI 10 o similar. No recopilamos conscientemente datos personales de menores de 13 anos. Los datos procesados (nickname, puntuaciones, correo electronico) no constituyen datos personales sensibles. El juego incluye una opcion para desactivar los efectos de sangre neón, permitiendo una experiencia mas amigable para todas las edades.

6. Servicios de terceros

La aplicacion utiliza los siguientes servicios de terceros:

  • Firebase Authentication (Google): autenticacion de usuarios mediante correo electronico y contrasena. Consulte la politica de privacidad de Google/Firebase en firebase.google.com/support/privacy.
  • Firebase Firestore (Google): almacenamiento de Nickname, Puntuaciones, solicitudes de canje, sugerencias, datos de seguridad y configuracion del juego. Consulte la politica de privacidad de Google/Firebase en firebase.google.com/support/privacy.
  • Pixabay (audio): musica de fondo libre de derechos. No se envian datos del usuario. Consulte pixabay.com/service/terms.

No utilizamos SDKs de analitica de terceros (como Google Analytics, Facebook SDK, etc.) ni SDKs publicitarios que recopilen datos del usuario.

7. Derechos del usuario (RGPD/LOPDGDD)

El usuario tiene derecho a:

  • Acceso: solicitar una copia de los datos almacenados (su Nickname, puntuaciones, solicitudes de canje y sugerencias enviadas).
  • Rectificacion: corregir datos inexactos (cambiar su Nickname desde la app).
  • Supresion: solicitar la eliminacion de sus puntuaciones del Ranking Global, solicitudes de canje, sugerencias y datos de seguridad asociados a su cuenta.
  • Portabilidad: recibir sus datos en formato estructurado.
  • Oposicion: oponerse al procesamiento de sus datos.

Para ejercer estos derechos, el usuario puede contactar a: privacidad@garrdashpe.app. Adicionalmente, el usuario puede borrar todos los datos locales desinstalando la aplicacion o limpiando los datos del navegador.

8. Modificaciones de esta politica

Nos reservamos el derecho de actualizar esta politica de privacidad en cualquier momento. Los cambios seran publicados en esta misma pagina con la fecha de actualizacion correspondiente. El uso continuado de la aplicacion despues de los cambios constituye la aceptacion de la nueva politica.

9. Contacto

Si tiene alguna pregunta, inquietud o solicitud relacionada con la privacidad de sus datos, puede contactarnos en: privacidad@garrdashpe.app.
